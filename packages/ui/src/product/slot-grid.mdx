# SlotGrid

## 1. Do czego służy

Tydzień wolnych terminów mentora w strefie czasowej oglądającego: uczeń przewija tygodnie i
wybiera jeden slot sesji (KONCEPCJA §U1, E3-S4). Strefa jest zawsze podpisana nad siatką, bo
rezerwacje między strefami to częsty błąd (KONCEPCJA Z9, brief reguła 10).

## 2. Kiedy używać

| Sytuacja w Kompasie | Źródło |
|---|---|
| Wybór terminu U1 (sesja próbna 30 min lub kolejna sesja z planu) | KONCEPCJA §U1 (SlotGrid), E3-S4 |
| Arkusz przełożenia sesji w U5 (`RescheduleSheet`) | KONCEPCJA §U5, E3-S6 |
| Tydzień dostępności na profilu P3 (tylko podgląd → prowadzi do U1) | KONCEPCJA §P3 (AvailabilityWeek), E2-S6 |

## 3. Kiedy nie używać

| Zamiast `SlotGrid` | Użyj | Źródło |
|---|---|---|
| Ustawianie dostępności przez mentora (szablon tygodnia, wyjątki) | edytor dostępności M3 (jeszcze nie ma w systemie) | KONCEPCJA §M3, E3-S2 |
| Lista umówionych sesji | `SessionListItem`, `TodayAgenda` | KONCEPCJA §U4, §M2 |
| Wybór długości sesji (30 / 60 min) | `ToggleGroup` nad siatką (`DurationToggle`) | KONCEPCJA §U1 |

| Część | Wymagana | Opis | Źródło |

## 7. Zachowanie i dostępność

| Zasada | Źródło |
|---|---|
| Kolejność Tab: „Poprzedni tydzień” → „Następny tydzień” → sloty dzień po dniu, od góry. | WCAG 2.4.3 |
| Slot to przycisk przełącznika: Enter lub Spacja wybiera; czytnik ogłasza grupę dnia i stan, np. „czw., 22 paź, grupa — 18:00, przycisk przełącznika, niewciśnięty”. | WAI-ARIA APG (Button, toggle), WCAG 4.1.2, story `SelectTest` |
| Dzień jako `fieldset` + `legend` — godzina ma kontekst dnia bez powtarzania daty w każdym przycisku. | WCAG 1.3.1 |
| Przyciski tygodnia z samą ikoną mają `aria-label` („Poprzedni tydzień”, „Następny tydzień”); ikony `aria-hidden`. | WCAG 4.1.2, 1.1.1 |
| Wybrany slot różni się nie tylko kolorem: ma `aria-pressed` dla czytnika i ramkę `selected-border`. | WCAG 1.4.1, 1.4.11 |
| W trakcie ładowania sekcja ma `aria-busy="true"`; szkielet jest `aria-hidden`. | WAI-ARIA 1.2 (`aria-busy`) |
| Każdy slot i przycisk tygodnia ma 44 px wysokości (minimum WCAG 24 × 24 px). | K1, WCAG 2.5.8 |

## 10. API

| Prop | Typ | Domyślnie | Opis |
|---|---|---|---|
| `status` | `'ready' \| 'loading' \| 'error'` | `'ready'` | `loading` → szkielet, `error` → `ErrorState` z „Ponów” |
| `days` | `DaySlots[]` (`{ date, slots: Slot[] }`, `Slot` = `{ id, startsAt }`) | — | 7 dni tygodnia; czasy ISO |
| `timeZone` | `string` (IANA) | — | strefa oglądającego, np. `Europe/Warsaw` |
| `timeZoneLabel` | `string` | nazwa IANA | podpis strefy, np. „Warszawa (GMT+2)” |
| `weekLabel` | `string` | — | zakres tygodnia, np. „19–25 października 2026” |
| `selectedSlotId` | `string` | — | id wybranego slotu |
| `onSelect` | `(slot: Slot) => void` | — | wybór slotu |
| `onPrevWeek` / `onNextWeek` | `() => void` | — | przewijanie tygodni |
| `canGoPrev` | `boolean` | `true` | `false` w bieżącym tygodniu |
| `nextAvailable` | `string` (ISO) | — | pierwszy wolny termin po tym tygodniu (stan pusty) |
| `onJumpToNext` | `() => void` | — | skok do tygodnia z `nextAvailable` |
| `onRetry` | `() => void` | — | „Ponów” w stanie błędu |
| `headingAs` | `'h2' \| 'h3'` | `'h2'` | poziom nagłówka tygodnia |
| `className` | `string` | — | tylko układ |

`SlotGridSkeleton` — sam szkielet siatki (używany wewnętrznie przy `status="loading"`).

## 11. Kod

```tsx
import { SlotGrid } from '@kompas/ui';

<SlotGrid days={days} timeZone={viewerTimeZone} weekLabel={weekLabel} />
```

## 13. Powiązane

- **Komponenty:** `HoldCountdown` (po wybraniu slotu, w U2), `PolicyNotice` (zasada 12 h w U1 i U5), `DateTime`, `EmptyState`, `ErrorState`, `Toast` (konflikt 409).
- **Mylony z:** edytorem dostępności M3, `ToggleGroup` (wybór jednej z kilku stałych opcji).
- **Wzorce:** wybór terminu z blokadą (U1 → U2), przełożenie sesji (U5).
