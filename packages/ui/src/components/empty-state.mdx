# EmptyState

## 1. Do czego służy

Informuje o braku danych na liście lub ekranie (stan pusty) — wyjaśnia przyczynę i wskazuje konkretny następny krok, aby użytkownik nie czuł się zagubiony.

<Controls of={EmptyStateStories.Playground} />

## 2. Kiedy używać

| Sytuacja w Kompasie | Źródło |
|---|---|
| Uczeń nie ma jeszcze żadnych zaplanowanych sesji w zakładce Nadchodzące (U4) | KONCEPCJA §U4 |
| Brak wyników po zastosowaniu zbyt wąskich filtrów w katalogu mentorów (P2) | prompt §Etap 3, KONCEPCJA §P2 |
| Pusta lista zapisanych ulubionych mentorów (E2-S8) | backlog §E2-S8 |
| Mentor nie otrzymał jeszcze żadnych nowych próśb o sesję (M2) | KONCEPCJA §M2 |

## 3. Kiedy nie używać

| Zamiast pustego stanu | Użyj | Źródło |
|---|---|---|
| Wystąpił błąd pobierania danych z serwera lub brak sieci | `ErrorState` z przyciskiem „Ponów” | prompt |
| Dane są w trakcie pobierania | `Skeleton` | prompt |
| Puste pole tekstowe w formularzu | `FieldDescription` lub placeholder | prompt |

## 4. Anatomia

| Część | Wymagana | Opis |
|---|---|---|
| Ikona / Ilustracja | opcjonalnie | Tematyczna, prosta ikona funkcyjna w kolorze `text-muted` (bez pstrokacizny) |
| Tytuł stanu | tak | Zwięzły nagłówek informujący, co się stało (`text-section-title` font-medium) |
| Opis | opcjonalnie | Wyjaśnienie przyczyny i podpowiedź kolejnego kroku (`text-body` text-muted) |
| Akcja główna | opcjonalnie | Przycisk prowadzący do rozwiązania (np. „Znajdź mentora”, „Wyczyść filtry”) |

## 5. Warianty

<Canvas of={EmptyStateStories.Variants} />

Dwa fundamentalne warianty logiczne:
1. **Pierwsze użycie („Jeszcze nic tu nie ma”):** zachęta do rozpoczęcia korzystania z produktu (np. rezerwacja pierwszej sesji).
2. **Brak wyników wyszukiwania:** informacja o braku dopasowania filtrów z przyciskiem resetującym kryteria.

## 10. API

| Komponent | Prop | Typ | Domyślnie | Opis |
|---|---|---|---|---|
| `EmptyState` | `title` | `ReactNode` | — | Tytuł stanu |
| `EmptyState` | `description` | `ReactNode` | — | Opis i wskazówka |
| `EmptyState` | `icon` | `ReactNode` | — | Opcjonalna ikona |
| `EmptyState` | `action` | `ReactNode` | — | Przycisk lub link akcji |

## 11. Kod

```tsx
<EmptyState
  icon={<Calendar className="size-icon-lg text-muted" />}
  title="Brak nadchodzących sesji"
  description="Nie masz jeszcze zaplanowanych spotkań. Przejrzyj profil mentora i umów sesję próbną."
  action={<Button>Znajdź mentora</Button>}
/>
```

Typowy przykład z produktu (U4): zakładka Moje sesje u nowego ucznia.
