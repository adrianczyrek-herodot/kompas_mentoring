# ToggleGroup

## 1. Do czego służy

Pozwala szybko przełączyć jedną (lub kilka) z 2–4 krótkich opcji, które zawsze są widoczne
obok siebie.

<Canvas of={ToggleGroupStories.Playground} />
<Controls of={ToggleGroupStories.Playground} />

## 2. Kiedy używać

| Sytuacja w Kompasie | Tryb | Źródło |
|---|---|---|
| Długość sesji 30 / 60 min w wyborze terminu (U1) | jeden | KONCEPCJA §U1 (`DurationToggle`) |
| Pora dnia w filtrze dostępności: rano / po południu / wieczorem (P2) | wiele (`multiple`) | KONCEPCJA §P2 |

## 3. Kiedy nie używać

| Zamiast przełącznika segmentowego | Użyj | Źródło |
|---|---|---|
| Przełączanie widoków z inną treścią (Nadchodzące / Minione) | `Tabs` (partia 3) | WAI-ARIA APG (Tabs) |
| Opcje z opisem albo dłuższe niż 2 słowa | `RadioGroup` | propozycja |
| Ustawienie wł./wył. | `Switch` | WAI-ARIA APG |
| Akcje | `Button` | WAI-ARIA APG |

## 4. Anatomia

| Część | Wymagana | Opis |
|---|---|---|
| Nazwa grupy | tak | `FieldTitle` + `aria-labelledby` |
| Ramka | tak | `border-control`, `rounded-control`, linie między opcjami |
| Opcja (`ToggleGroupItem`) | tak, 2–4 | min. 44 px, `text-label`, odstęp 12 px (`field-x`), etykieta zawija się na wąskim ekranie; ikona opcjonalna |

## 7. Zachowanie i dostępność

| Zasada | Źródło |
|---|---|
| Opcje to przyciski z `aria-pressed`; grupa `group` z nazwą. | WAI-ARIA APG (Toolbar / Button) |
| Strzałki przechodzą między opcjami, Enter / Spacja wybiera; fokus zapętla się. | Base UI, WAI-ARIA APG |
| Wybór widać też grubością tekstu, nie tylko kolorem. | WCAG 1.4.1 |
| Opcje 44 px wysokości. | K1 |

## 10. API

| Komponent | Prop | Typ | Domyślnie | Opis |
|---|---|---|---|---|
| `ToggleGroup` | `value` / `defaultValue` | `string[]` | — | wybrane opcje (tablica także dla jednego wyboru) |
| `ToggleGroup` | `onValueChange` | `(value: string[]) => void` | — | zmiana |
| `ToggleGroup` | `multiple` | `boolean` | `false` | wiele opcji |
| `ToggleGroup` | `disabled`, `aria-labelledby` | — | — | blokada, nazwa grupy |
| `ToggleGroupItem` | `value`, `disabled` | `string`, `boolean` | — | opcja |

## 11. Kod

```tsx
<ToggleGroup aria-labelledby="duration" defaultValue={['30']}>
  <ToggleGroupItem value="30">30 min</ToggleGroupItem>
  <ToggleGroupItem value="60">60 min</ToggleGroupItem>
</ToggleGroup>
```

Typowy przykład z produktu (U1): wartość steruje siatką slotów —
`onValueChange={([minutes]) => setDuration(Number(minutes))}`.

## 13. Powiązane

- **Mylony z:** `Tabs` (widoki), `RadioGroup` (opcje z opisem), `Switch`.
- **Wzorce:** wybór terminu z blokadą (U1), lista z filtrami (P2).
