# Select

## 1. Do czego służy

Pozwala wybrać jedną wartość z krótkiej, znanej listy, gdy opcji jest za dużo, żeby pokazać je
wszystkie naraz.

<Canvas of={SelectStories.Playground} />
<Controls of={SelectStories.Playground} />

## 2. Kiedy używać

| Sytuacja w Kompasie | Źródło |
|---|---|
| Sortowanie wyników wyszukiwarki: trafność, cena, ocena, liczba sesji (P2) | KONCEPCJA §P2 |
| Strefa czasowa ucznia i mentora (U1, S3) | KONCEPCJA §U1, §S3, brief reguła 10 |
| Minimalne wyprzedzenie rezerwacji 2–48 h i bufor 0–30 min (M3) | KONCEPCJA §M3 |

## 3. Kiedy nie używać

| Zamiast listy rozwijanej | Użyj | Źródło |
|---|---|---|
| 2–4 opcje, które warto widzieć od razu („uczyć się / mentorować”) | `RadioGroup` | KONCEPCJA §P4, WAI-ARIA APG |
| 2–3 opcje przełączane często (30 / 60 min) | `ToggleGroup` | KONCEPCJA §U1 |
| Długa lista, w której szukasz po nazwie (tematy, tagi) | `Combobox` | Base UI (Select nie filtruje) |
| Wybór kilku opcji | `Combobox multiple` albo `Checkbox` w grupie | — (propozycja) |
| Akcje („Edytuj”, „Usuń”) | `Menu` (partia 4) | WAI-ARIA APG (Menu) |

## 4. Anatomia

| Część | Wymagana | Opis |
|---|---|---|
| Etykieta | tak | `FieldLabel htmlFor` = `id` pola |
| Pole (`SelectTrigger`) | tak | wygląd `Input`: 44 px, `border-control`, strzałka |
| Wartość (`SelectValue`) | tak | wybrana opcja albo `placeholder` (przykład, nie nazwa) |
| Lista (`SelectContent`) | tak | panel `surface-panel`, `rounded-panel`, `shadow-overlay`, pod polem |
| Opcja (`SelectItem`) | tak | 44 px, znacznik ✓ przy wybranej |
| Grupa i separator | nie | `SelectGroup` + `SelectGroupLabel`, `SelectSeparator` |

## 5. Warianty

<Canvas of={SelectStories.Variants} />

Jeden wygląd. Odmiany treści: z grupami (strefy według kontynentu), z podpowiedzią, z placeholderem,
gdy nie ma sensownej wartości domyślnej. Lista otwiera się zawsze pod polem
(`alignItemWithTrigger={false}`), żeby nie zasłaniać etykiety (propozycja).

| Zasada | Źródło |

## 10. API

| Komponent | Prop | Typ | Domyślnie | Opis |
|---|---|---|---|---|
| `Select` | `value` / `defaultValue` | `string \| null` | — | wybrana wartość |
| `Select` | `onValueChange` | `(value) => void` | — | zmiana wyboru |
| `Select` | `items` | `{ value, label }[]` | — | etykieta wartości w polu przed otwarciem listy |
| `Select` | `disabled`, `required`, `name` | `boolean`, `boolean`, `string` | — | formularz |
| `SelectTrigger` | `id`, `aria-invalid`, `aria-describedby` | — | — | etykieta, błąd, podpowiedź |
| `SelectValue` | `placeholder` | `ReactNode` | — | tekst bez wyboru |
| `SelectContent` | `sideOffset` | `number` | `4` | odstęp listy od pola (px) |
| `SelectItem` | `value`, `disabled` | `string`, `boolean` | — | opcja |

## 11. Kod

```tsx
<Field>
  <FieldLabel htmlFor="sort">Sortowanie</FieldLabel>
  <Select items={options} defaultValue="relevance">
    <SelectTrigger id="sort"><SelectValue /></SelectTrigger>
    <SelectContent>
      {options.map((o) => <SelectItem key={o.value} value={o.value}>{o.label}</SelectItem>)}
    </SelectContent>
  </Select>
</Field>
```

Typowy przykład z produktu (P2, sortowanie w URL):

```tsx
<Select items={sortOptions} value={params.sort} onValueChange={(sort) => setParam('sort', sort)}>
  <SelectTrigger id="sort"><SelectValue /></SelectTrigger>
  <SelectContent>
    {sortOptions.map((o) => <SelectItem key={o.value} value={o.value}>{t(o.labelKey)}</SelectItem>)}
  </SelectContent>
</Select>
```

## 13. Powiązane

- **Mylony z:** `Combobox` (filtrowanie), `RadioGroup` (opcje widoczne), `Menu` (akcje, nie wartości).
- **Wzorce:** lista z filtrami (sortowanie P2), formularz (ustawienia M3, S3), wybór terminu (strefa czasowa U1).
