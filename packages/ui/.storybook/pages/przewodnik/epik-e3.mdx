# Epik E3: Dostępność i rezerwacje

Wybór terminu, sesje, przełożenie/anulowanie, panel mentora, powiadomienia.

## Przepływ

1. **U1 Wybór terminu** — tydzień, siatka slotów, długość, strefa, blokada (hold), countdown
2. **U4 Moje sesje** — lista nadchodzących/minionych, status, akcja „Dołącz”
3. **U5 Szczegóły sesji** — najważniejsze info + akcja, reguła 12 h, przełożenie/anulowanie
4. **M2 Panel mentora** — prośby o sesję próbną (akceptuj/odrzuć z powodem), agenda dnia
5. **M3 Kalendarz** — szablon tygodnia, wyjątki, ustawienia (Later)
6. **S2 Powiadomienia** — lista z akcjami (Later)

## Wzorce używane

- **Wybór terminu z blokadą** (U1) — `SlotGrid` + `HoldCountdown` + `SlotHold` pattern
- **Zmiana z regułą 12 h** (U5) — `PolicyNotice` + `CancelDialog` + `RescheduleSheet` + `Change12h` pattern
- **Decyzja z powodem** (M2) — `TrialRequestCard` + `DeclineDialog` + `DecisionReason` pattern
- **Lista z filtrami** (U4) — `SessionListItem` + `BookingStatusBadge` + filtry statusu
- **Widok szczegółów** (U5) — `NextSessionCard` + `PolicyNotice` + akce
