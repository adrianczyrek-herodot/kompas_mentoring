# Epik E2: Katalog i onboarding

Strona główna, wyszukiwarka, profil mentora, onboarding mentora, weryfikacja.

## Przepływ

1. **P1 Strona główna** — wyszukiwanie tematów, kategorie, CTA „Zostań mentorem”
2. **P2 Wyszukiwarka** — lista mentorów z filtrami, sortowaniem, siatką wyników
3. **P3 Profil mentora** — hero, statystyki, tagi, opis, widoczność, StickyBookingBar
4. **M1 Onboarding mentora (kroki 1–6)** — tożsamość, opis+wideo, stawka, dostępność, kalendarz, podsumowanie
5. **A1 Weryfikacja** — kolejka wniosków, checklisty, forma decyzji
6. **E2-S8 Ulubieni mentorzy** — (zostawiony na test agentem)
