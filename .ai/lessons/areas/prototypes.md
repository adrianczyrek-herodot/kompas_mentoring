# Lekcje — Prototypy

Plik obszarowy lekcji (zasady: `AGENTS.md` → „Lekcje”). Czytaj, gdy router w `AGENTS.md` wskazuje ten obszar: `prototypes/*` (kompas-flow, discovery), mapy ekranów.

- **2026-11-21** — Prototyp `prototypes/kompas-flow` był raportowany jako „build OK”, a `npm run build` (`tsc && vite build`) padał na 156 błędach TS; samo `vite build` nie sprawdza typów, więc przechodziło mimo wywołań nieistniejących funkcji (5 ekranów crashowało). „Działa” = `tsc --noEmit` z kodem 0 **i** przejście ekranów w przeglądarce bez `pageerror`. Pakiet dopisany do `pnpm-workspace.yaml` wchodzi do `turbo build/typecheck` całego repo. Szczegóły: [runs/2026-11-21-przeglad-prototypu-kompas-flow.md](../../runs/2026-11-21-przeglad-prototypu-kompas-flow.md)
- **2026-11-22** — Prototyp HTML z discovery (`prototypes/discovery/*/revision-*/index.html`) potrafi „działać” w 22 z 24 scenariuszy, a **nie pokazywać żadnego stanu poza domyślnym**: bloki wariantów miały klasę `hidden` (`display:none !important`), a reguły CSS ukrywały nawet właściwy blok. Weryfikacja prototypu musi obejmować **macierz stanów** (dla każdego ekranu ustawić każdy wariant i sprawdzić, że widoczny jest dokładnie jeden blok z treścią), nie tylko kliknięcie scenariuszy. Widocznością stanów powinno sterować jedno miejsce w JS (`applyState`), a nie klasy w treści + reguły CSS.
- **2026-11-22** — Prototyp z discovery leży w `prototypes/discovery/<slug>/revision-NNN/` (z `prototype.json` i `README.md`), a mapa ekranów w `prototypes/<slug>/mapa-ekranow.md` — to dwa różne artefakty. Do frontmattera specyfikacji wchodzi ścieżka **folderu prototypu z rewizją**, nie katalog mapy. README prototypu zawiera założenia `A-*` i bywa sprzeczny z późniejszymi decyzjami właściciela — rozbieżności zapisujemy w specyfikacji („Decyzje i zmiany”), a prototyp poprawiamy osobno, zamiast po cichu zmieniać artefakt innego zadania.
- **2026-11-21** — Prototyp poza `apps/` (np. `prototypes/*`) z hash-routerem: `AppHeader` renderuje sztywne `href="/sesje"` bez `render`, więc kliknięcia trzeba przechwycić i zamienić na nawigację routera (`interceptAppLinks` w `prototypes/kompas-flow/src/lib/router.ts`).
