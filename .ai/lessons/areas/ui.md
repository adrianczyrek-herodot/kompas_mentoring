# Lekcje — UI i design system

Plik obszarowy lekcji (zasady: `AGENTS.md` → „Lekcje”). Czytaj, gdy router w `AGENTS.md` wskazuje ten obszar: `packages/ui`, Storybook, tokeny CSS, Tailwind, komponenty i kontrast.

- **2026-11-11** — TypeScript pomija katalogi z kropką przy `include: [".storybook"]` — `tsc` po cichu nie sprawdzał `.storybook/`, a ESLint (project service) zgłaszał „not found by the project service”. Podawaj jawne wzorce: `".storybook/**/*.ts"`, `".storybook/**/*.tsx"`; sprawdzaj `tsc --listFilesOnly`.
- **2026-11-11** — Storybook: strony MDX bez stories nie uruchamiają dekoratorów, więc przełącznik motywu oparty tylko na dekoratorze nie działa na stronach dokumentacji. Motyw na `<html>` ustawiaj też z kanału (`SET_GLOBALS`, `GLOBALS_UPDATED`) w `preview.tsx`.
- **2026-11-11** — Zmienna CSS zdefiniowana jako `var(--inna)` na `:root` jest rozwiązywana raz, na korzeniu, i dziedziczona już jako wartość — w poddrzewie `.dark` / `.light` alias (np. `--card: var(--surface-panel)`) zostaje z motywu korzenia. Aliasy i tokeny komponentów deklaruj na `:root, .light, .dark`.
- **2026-11-11** — Wynik `build-storybook` (`storybook-static/`) musi być wykluczony z ESLint (`packages/config/eslint`), dependency-cruiser (`.dependency-cruiser.cjs`) i `.gitignore`, inaczej `pnpm lint` zgłasza tysiące błędów w zbudowanych plikach.
- **2026-11-21** — `cn()` (tailwind-merge) nie zna własnych rozmiarów tekstu z `@theme` — `text-label` brał za kolor i usuwał go obok `text-text-default` (lub odwrotnie), po cichu. Każdą nową rolę `--text-*` w `globals.css` dopisz do `extendTailwindMerge` w `packages/ui/src/lib/utils.ts`.
- **2026-11-21** — Testy stories (Vitest browser) padały całymi plikami („Failed to fetch dynamically imported module”, „Vite unexpectedly reloaded a test”), gdy story importowała zależność, której Vite jeszcze nie zoptymalizował. `optimizeDeps.entries` skanuje tylko przy przebudowie pamięci podręcznej, więc w `packages/ui/vitest.config.ts` jest też `force: true` (ok. 4 s na start). Nie dodawaj do `entries` `main.ts` (ładuje natywny `@tailwindcss/oxide`).
- **2026-11-21** — Bloki Storybooka (tabela propsów `docblock-argstable`, kod `docblock-source`) mają style tylko jasne — w ciemnym motywie trzeba je nadpisać w `.storybook/preview.css` (podwójna klasa, żeby wygrać z emotion). Sprawdzaj każdą nową stronę w obu motywach.
- **2026-11-21** — Nakładki Base UI (Select, Combobox, później Menu, Dialog) wchodzą i wychodzą z animacją przezroczystości: w play function `toBeVisible()` zaraz po otwarciu i „fokus wrócił na pole” / „lista zniknęła” zaraz po wyborze padają. Takie asercje owijaj w `waitFor(...)`. Dotyczy też `Tabs`: po przełączeniu stary panel jest chwilę w DOM (`data-ending-style`), więc `getByRole('tabpanel')` znajduje dwa — sporadyczne błędy pełnego przebiegu miały tę przyczynę.
- **2026-11-21** — `packages/ui/POSTEP.md` i `docs/design-system.md` wymieniają 45 komponentów produktu, a `packages/ui/src/index.ts` eksportuje 16 (brak m.in. `FilterPanel`, `WeekPicker`, `PasswordField`, `OnboardingStepper`; `FilterPanel` jest tylko w `.storybook/examples`). Przed planowaniem ekranu sprawdzaj eksport `index.ts`, nie dokumentację. `BottomNav` nie jest osobnym komponentem — jest w `AppHeader`.
- **2026-11-23** — `biome check --write <katalog>` formatuje też pliki spoza zakresu zadania (na `apps/web/app/mentor` przepisał formularze onboardingu M1 i `layout.tsx`) — uruchamiaj na dokładnej liście zmienianych plików albo przejrzyj `git status` przed commitem i cofnij obce zmiany (`git checkout -- <plik>`). `pnpm lint` (`lint:biome` nie jest jego częścią) tego nie wymusza.
- **2026-11-21** — Od etapu 1 design systemu alias shadcn `--primary` = `action-primary` (bursztynowe wypełnienie przycisku), więc `text-primary` / `border-primary` na tle strony nie spełnia kontrastu — e2e (axe `color-contrast`) padło w PR #54. Tekst-akcent i linki: `text-text-link`, zaznaczenie: `border-selected-border`; `primary` tylko jako tło z `primary-foreground`. Po zmianie tokenów uruchom e2e (wymaga Dockera albo CI).
