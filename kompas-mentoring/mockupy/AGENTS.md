# Mockupy (`kompas-mentoring/mockupy`)

Stare klikalne mockupy (TypeScript, bundle w `dist/app.js`); produkt rozwijamy w `apps/` i `prototypes/`.

- Sprawdzenie zmian: `cd kompas-mentoring/mockupy && npm run typecheck && npm run build`, potem przejście zmienionego przepływu w przeglądarce (`npm run dev`).
